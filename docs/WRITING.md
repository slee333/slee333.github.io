# 글쓰기와 발행

지금 기본 방식은 Obsidian으로 쓰는 것입니다. 노션에서 가져오는 방식은 아래 "Notion에서 가져오기"에 그대로 있습니다.

## Obsidian으로 쓰기

### 한눈에 보기

| 단계 | 하는 일 | 어디서 |
|---|---|---|
| 1. 글감 | 쓸거리와 확인한 출처를 모아 둔다 | `_작업/2026 글감 정리.md`, `_작업/글 후보 로그.md` |
| 2. 초안 | 템플릿으로 새 초안을 만든다 | Obsidian, `docs/_drafts` |
| 3. 미리보기 | 쓰면서 화면을 본다 | 4000번 (글·레이아웃), 4002번 (이미지 포함) |
| 4. 검토 | 사실 확인, 맞춤법, 대체 텍스트, 출처 | 직접 또는 Claude에게 요청 |
| 5. 발행 준비 | 이미지 최적화, 썸네일, 포스트 폴더로 이동 | `python blog.py ready` |
| 6. 번역 | 한국어가 확정되면 영어·스페인어로 | `docs/_posts/en`, `docs/_posts/es` |
| 7. 배포 | 이 글과 쓰는 이미지만 커밋하고 푸시 | `gh-pages` |

`_작업` 폴더와 `docs/_media`는 git에서 빠져 있어 공개되지 않습니다.

### 1. 새 초안 만들기

Obsidian에서 새 노트를 만들면 `docs/_drafts`에 생깁니다. 템플릿 삽입으로 시작하세요. 템플릿 폴더는 `docs/_templates`입니다.

| 템플릿 | 쓰는 글 |
|---|---|
| 정리 글 | 가이드라인 모아보기처럼 계속 고쳐 가는 정리 글. 목차, 면책 문구, 참고문헌 자리가 들어 있음 |
| 주간 읽기 | 이번 주 읽은 논문 2–3편 |
| 직접 해본 기록 | 펠로우 생활, 도구, 작은 프로젝트 |
| 블로그 글 | 그 밖의 글 |

front matter에서 꼭 볼 항목:

- **translation_id:** 영문 소문자와 하이픈으로 된 주소 이름입니다. 예를 들어 `guideline-roundup-2027-part-1`이면 주소가 `/learning/guideline-roundup-2027-part-1/`이 됩니다. 비워 두면 발행 준비가 멈춥니다. 번역본도 같은 값을 씁니다.
- **categories:** `cifellowship`(의료정보학), `learning`(공부일기), `research`(독서와 연구), `life`(일상기록) 중 하나입니다.
- **image:** 대표 이미지입니다. `/assets/images/posts/opt-....webp`처럼 씁니다. 본문 이미지 중 하나를 골라도 됩니다. 없으면 비워 둡니다.
- **featured:** `true`면 홈 "처음 오셨다면"에 올라갑니다. 최신 글부터 두 개까지 보입니다.
- **toc:** 소제목이 많은 긴 글이면 `true`로 둡니다. 글 위에 접히는 목차가 생깁니다.

템플릿의 안내 문구는 front matter 주석(`#`)에 있습니다. 본문에 HTML 주석(`<!-- -->`)을 남기면 공개 페이지 소스에 그대로 보이니, 발행 전에 지워 주세요.

### 2. 쓰면서 미리보기

- **4000번:** 글과 레이아웃을 빠르게 볼 때 씁니다. 저장할 때마다 자동으로 새로고침되고, 초안도 보입니다. Claude 앱에서는 미리보기 설정의 "jekyll"이고, 직접 띄우려면 `docs` 폴더에서 `bundle exec jekyll serve --drafts --livereload`를 실행합니다. 초안 속 로컬 이미지는 여기서 깨져 보이는 게 정상입니다.
- **4002번:** 이미지까지 볼 때 씁니다. `python blog.py preview`를 실행하면, 붙여 넣은 이미지를 최적화하고 초안의 이미지 링크를 최적화본으로 바꾼 뒤 별도 복사본으로 보여 줍니다. 초안 파일을 고치는 명령이라 Obsidian이 자동 저장 중이 아닐 때 실행하세요.

### 3. 이미지

- 붙여 넣은 이미지는 `docs/_media/originals`에 원본으로 저장됩니다. 이 폴더는 이 컴퓨터에만 있으니 따로 백업해 두세요.
- 최적화 규칙 (`blog.py`):
  - JPEG 사진은 최대 1600px, AVIF 품질 60입니다.
  - PNG는 폭 1600px까지 줄여 WebP로 저장합니다. 무손실 결과가 300KB를 넘고 품질 85 손실 압축이 30% 이상 작으면 손실 압축을 씁니다.
  - GIF, 움직이는 이미지, SVG는 그대로 둡니다.
- 대표 이미지는 `w240`, `w800` 썸네일이 자동으로 만들어져 홈과 목록에 쓰입니다. 미리보기·발행 준비 때 자동으로 만들어지고, 따로 만들려면 `python blog.py thumbs`를 실행합니다.
- 본문 이미지는 지연 로딩됩니다. 이미지마다 대체 텍스트(`![여기](...)`)를 한 문장으로 적어 주세요.

### 4. 검토

- 의학 글은 수치와 권고를 원문과 대조합니다. 글 끝에 참고문헌(DOI 링크)을 두고, 머리말 아래에 면책 문구를 둡니다.
- 맞춤법, 약 이름 철자, 띄어쓰기를 봅니다.
- 다른 학술지·서비스 그림을 쓰면 캡션에 출처를 적습니다.

### 5. 발행 준비

```powershell
python blog.py ready _drafts/파일이름.md
```

이미지를 최적화하고, 썸네일을 만들고, 초안을 `docs/_posts/kr/카테고리/날짜-주소.md`로 옮깁니다. 커밋이나 공개는 하지 않습니다. 초안 파일이 옮겨지므로 Obsidian에 열린 초안 창은 닫힙니다.

### 6. 번역

새 글은 한국어 원문이 확정된 뒤 영어·스페인어판도 만드는 것을 기본으로 합니다. 기계 번역으로 충분하고, 제목과 약 이름, 고유명사만 따로 확인합니다.


- `docs/_posts/en/카테고리/`, `docs/_posts/es/카테고리/`에 같은 파일 이름으로 만듭니다.
- front matter는 한국어 글을 복사하고 `lang`(`en`/`es`), `title`, `subtitle`, `permalink`(`/en/카테고리/주소/`)만 바꿉니다. `translation_id`는 그대로 둡니다.
- 이미지 경로는 `/assets/images/posts/...` 절대 경로로 씁니다. 번역본은 주소가 한 단계 깊어 상대 경로가 깨집니다.
- 같은 `translation_id`면 언어 전환 메뉴와 언어 안내 배너가 자동으로 연결됩니다.

### 7. 배포

- `git add .`로 전체를 올리지 말고, 이 글 파일과 쓰는 이미지, 썸네일(`w240`, `w800`)만 골라 커밋합니다.
- `gh-pages`에 푸시하면 1분 안팎으로 공개 사이트에 반영됩니다.

### Claude에게 이렇게 요청하면 됩니다

> 글감 정리의 ○○ 항목으로 정리 글 초안을 만들어 줘.

> 이 초안 내용을 원문과 대조해서 검증해 줘. 고치지는 말고 결과만.

> 미리보기 띄워 줘.

> 맞춤법이랑 사실관계만 고치고 발행 준비해 줘.

> 이 글 영어·스페인어 번역 만들어 줘.

> 이 글이랑 이미지만 커밋하고 배포해 줘.

## Notion에서 가져오기

### 평소에는 이렇게 요청하세요

노션에서 원고를 완성한 뒤 이 프로젝트에서 다음처럼 요청하면 됩니다.

> 이 노션 글을 가져와서 변경사항과 미리보기를 보여줘: [노션 링크]

미리보기를 본 뒤:

> 이 검토본을 블로그에 반영해줘.

공개 사이트에 올릴 준비가 되면:

> 이번 글과 필요한 이미지만 커밋하고 배포해줘.

가져오기·미리보기는 기존 발행본을 바꾸지 않습니다. `apply`도 로컬 파일만 반영하며, Git 커밋이나 푸시는 하지 않습니다. 현재 프로젝트에 다른 작업이 함께 있으므로 `git add .`로 전체를 한꺼번에 발행하지 마세요.

### 노션 원고

원고의 기준은 노션입니다. 발행 후 고칠 때도 노션에서 수정하고 다시 가져오세요.

- **title**: 제목. 노션의 기본 제목 속성도 인식합니다.
- **categories**: `life`, `learning`, `research`, `cifellowship` 중 하나.
- **date**: 발행일. 비워두면 가져온 날의 UTC 날짜입니다.
- **lang**: `kr`(기본), `en`, `es`.
- **subtitle**: 한 줄 요약. 비워도 됩니다.
- **translation_id**: 같은 글의 번역본들이 공유하는 고정 ID. 발행 후 바꾸지 마세요.
- **filename**: 새 글의 영문 파일 이름. 선택 사항입니다.
- **tags**: 선택 사항입니다.
- **image**: 대표 이미지 파일/URL. 없으면 노션 커버, 둘 다 없으면 이미지 없이 발행합니다.
- **featured**: 체크한 글을 홈 대표 글로 우선 사용합니다. 최근 글부터 최대 2개를 보여주며, 자리가 남으면 `_data/home_featured.yml`의 기본 추천으로 채웁니다.

한국어 글을 먼저 발행하고, 필요한 글만 번역하세요. 이 도구는 번역문을 자동 생성하지 않습니다. 번역 원고에는 같은 translation_id와 다른 lang을 지정하면 언어별 주소를 생성합니다. 기존 글의 주소는 다시 가져와도 유지합니다.

### 최초 설정

프로젝트의 `docs` 폴더에서 실행합니다.

```powershell
python -m pip install -r requirements-writing.txt
```

`docs/.env`에 `NOTION_TOKEN`을 설정하고, 가져올 노션 페이지에 해당 연결의 읽기 권한을 부여하세요. 기존 토큰을 그대로 사용할 수 있습니다. `.env`는 커밋하거나 공유하지 않습니다.

새 이미지는 Cloudinary에 업로드하지 않고 블로그의 `assets/images/posts/`에 저장합니다. 같은 이미지 내용은 같은 파일 이름을 사용하므로 재가져오기 시 발행 저장소에 중복 파일이 생기지 않습니다. 노션의 만료되는 이미지 주소는 발행본에 남기지 않습니다. 기존 글의 Cloudinary 이미지는 그대로 유지됩니다. 사진이 많으면 저장소가 커지므로 업로드 전 적절히 줄여 주세요. 이미지 한 장의 가져오기 상한은 25 MB입니다.

### 직접 실행하기

```powershell
python new_blog_workflow.py import "노션 페이지 URL"
```

카테고리 속성이 없는 일반 페이지라면 `--category life --slug new-york-weekend`를 덧붙이세요. 결과에 표시되는 검토 ID를 아래 명령의 `검토ID` 자리에 넣습니다.

```powershell
python new_blog_workflow.py review 검토ID
python new_blog_workflow.py preview 검토ID
```

미리보기는 원본 사이트를 별도로 복사해 만듭니다. 기본 주소는 `http://127.0.0.1:4001`이며, 명령이 출력하는 해당 글 주소를 여세요. 기존 4000번 미리보기와 분리됩니다. 종료는 Ctrl+C입니다. 이미 사용 중인 포트라면 `--port 4002`로 변경할 수 있습니다.

```powershell
python new_blog_workflow.py apply 검토ID
bundle exec jekyll build
bundle exec jekyll doctor
```

`apply`는 가져온 시점 이후 로컬 글이 바뀌었으면 덮어쓰지 않고 중단합니다. 그때는 노션 원본에 수정사항을 합친 다음 다시 가져와 차이를 검토하세요. 적용 전 원본은 검토 폴더의 `before.md`에 보관됩니다. 검토본을 직접 고치기보다 노션에서 수정 후 다시 가져오는 흐름을 권장합니다.

최종 Git 변경사항에서 해당 글과 필요한 이미지, 의도한 디자인 변경만 선택해 커밋·푸시합니다. 실제 공개 여부는 GitHub Pages 배포 완료 후 확인합니다.

### 지원 범위와 보관

본문·제목·링크·강조·코드·중첩 목록·체크리스트·인용·콜아웃·토글·표·이미지·캡션을 변환합니다. 노션 컬럼은 읽기 순서로 합칩니다. 임베드는 링크로 표시합니다. 동영상·첨부 파일 등 지원하지 않는 블록이 있으면 조용히 누락하는 대신 가져오기를 중단합니다.

변환 파일은 Jekyll Markdown 컨테이너 안에 HTML로 본문 구조를 보존합니다. 코드 안의 Liquid 문법은 실행되지 않도록 처리합니다.

`.blog-workflow/`에는 원고·이미지·백업·미리보기 복사본이 있습니다. Git과 사이트 빌드에서 제외됩니다. 오래된 검토/미리보기 폴더는 필요가 없어졌을 때 삭제해 용량을 정리할 수 있습니다.

구현 참고: [Notion 블록 가져오기](https://developers.notion.com/reference/get-block-children).
