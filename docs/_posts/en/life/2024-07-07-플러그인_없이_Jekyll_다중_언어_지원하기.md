This time, as I start a new blog, I have a small desire. I wanted to support the blog in our language (Korean), English, and Spanish (!).



As the platform to start the new blog, I chose Jekyll, but I encountered various difficulties with commonly used plugins such as **multiple-languages-plugin** and **polyglot**. The issue was that posts and pages needed to be stored in subfolders, which Jekyll did not recognize. Additionally, the sitemap was not automatically generated.



So, I ended up mixing in some hardcoding to implement a multilingual blog. The process is simple, and I will briefly summarize it below.

The structure is simple. As those who use Jekyll already know, Jekyll's pages can be accessed via **base URL** and **detailed URL**. In my case, the base URL corresponds to the basic page of the blog, `slee333.github.io`, and the detailed URL is `about`.



If a language is inserted between the base URL and the detailed URL, it will redirect to the page in that language. However, for the default language, Korean, it allows direct access to the post or page via `{base URL}/{detailed URL}` without this process.



By this point, you probably realize, <span style='color:blue'>*What? You can just create two pages or posts, assign one the regular URL, and the other an address with /{language}/ inserted?*</span> That's correct. Set up the front matter as follows:

After setting this up, you can easily switch languages within the About page by adding `en` in front of `/about/` when switching from `kr` → `en`, and removing `en` from the URL when switching from `en` → `kr`. You’ll also see an attribute `lang` in the front matter to denote the language of each page, which is useful for identifying the language of the current page.

The point is to set the `permalink` as <span style='color:green'>/:title/</span>. For English posts, the `permalink` will naturally be <span style='color:green'>/en/:title/</span>. Here, `title` refers to the filename of the markdown file in which the post is written. (For example, in **2024-07-01-MyDiary**, **MyDiary** becomes <span style='color:green'>:title</span>, and the post's `permalink` will also be `/MyDiary`.)



In a nutshell, if you provide the same content in different languages with the same filenames, you can support multiple languages using the aforementioned <span style='color:green'>:title </span> feature and language URL structure.



Naturally, a question arises:



> How do you store these files together in the same folder if they have the same names?



It's a valid point. Therefore, create separate language folders within `_posts` to store the files differently. I organize my posts into folders by language and category within `_posts`.

## 2. Creating a Language Switch Button



Now that we have two pages matching two languages, it's time to create a method for users to switch between pages in different languages. I created a `header.html` in `root/_includes` to be used as the header for all pages/posts, and added the following element to that header.



![](https://prod-files-secure.s3.us-west-2.amazonaws.com/0401ca2c-0b04-4c4d-9f2f-d423516f4fae/fcb52e39-320b-4e11-b3b7-8a4883e76acb/Untitled.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&X-Amz-Credential=AKIAT73L2G45HZZMZUHI%2F20240708%2Fus-west-2%2Fs3%2Faws4_request&X-Amz-Date=20240708T205734Z&X-Amz-Expires=3600&X-Amz-Signature=4087d62db64281108315678d4dbc90ff2ac6a929455484a4db244c549c6391d9&X-Amz-SignedHeaders=host&x-id=GetObject)

This div element has an id of `language-select` and functions as a dropdown. When the current page is in Korean (`page.lang == ‘kr’`), the option with value "kr" is selected. Conversely, when it is in English, the option with value ‘en’ is selected. On my page, it looks like this:

## 3. Linking the Language Switch Button with Redirect Function



Now it's time to add the function to this dropdown to redirect to the corresponding URL when another language is clicked. I added the following JavaScript inside the `<script>` tag in `header.html`:


`<script>`

   ```javascript
// Select the language-select element mentioned earlier.
const languageSelect = document.getElementById('language-select');
languageSelect.addEventListener('change', function () {
  // When the option of the language-select changes, input the current value into the redirectPage function.
  // This means that the option values "kr", "en", "es", etc., are inputted.
  redirectPage(this.value);
});

// redirectPage function.
function redirectPage(selectedLang) {
  let currentUrl = window.location.pathname;
  // If the current URL starts with /en/ or /es/, remove that part.

  if (currentUrl.startsWith('/en/') || currentUrl.startsWith('/es/')) {
    currentUrl = currentUrl.replace(/^\/(en|es)\//, '/');
  }

  // If the input value is not "kr", insert the selected language (es or en in this example) at the front of the URL.
  if (selectedLang !== 'kr') {
    currentUrl = `/${selectedLang}${currentUrl}`;
  }

  // Clean up any redundant / characters.
  currentUrl = currentUrl.replace(/\/+/g, '/');

  // Redirect to the new URL!
  window.location.href = `${window.location.origin}${currentUrl}`;
}

  ```

`</script>`

## 4. Updating the Navbar



I haven’t explained how to change the menu items (Introduction, Daily Records, etc.) in the top navigation bar when the language is switched. The simplest method is to hardcode it in the navbar (which was my initial approach):



```html

<nav class="site-nav">
  <div class="menu-toggle" id="menu-toggle">&#9776;</div> <!-- Hamburger icon -->
  <div class="trigger navbar">

    {% if page.lang == 'kr' %}
    <a class="page-link" href="{{ site.baseurl }}/about">소개</a>
    <a class="page-link" href="{{ site.baseurl }}/life">일상</a>

    <!-- Etc. .. -->
    {% endif %}
    {% if page.lang == 'en' %}
    <a class="page-link" href="{{ site.baseurl }}/en/about">About</a>
    <a class="page-link" href="{{ site.baseurl }}/en/life">Life</a>
    <!-- Etc. .. -->
    {% endif %}

    <!-- The previously used language-switcher -->
    <div class="language-switcher">
      <select id="language-select">
        <option value="kr" {% if page.lang=='kr' %}selected{% endif %}>한국어</option>
        <option value="en" {% if page.lang=='en' %}selected{% endif %}>English</option>
        <option value="es" {% if page.lang=='es' %}selected{% endif %}>Español</option>
      </select>
    </div>
  </div>
</nav>

```



By using Liquid's if functionality, the Korean menu appears if the page language is `kr`, and the English menu appears if the language is `en`. This method works perfectly fine.



Currently, I've modified the code to go beyond hardcoding, and I will describe this method further in a subsequent post.
